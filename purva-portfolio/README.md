# Purva Sikarwar · Portfolio

Personal portfolio site, told as a journey from Mandsaur to Stockholm, with an avatar guide.

## Files
- `index.html` – the whole site (HTML, CSS and JS in one file)
- `avatar/` – avatar poses, turn-around angles and the header face
- `netlify.toml` – Netlify settings (no build step)

## Edit and publish a new version
1. Edit `index.html` (on github.com: open the file → pencil icon → Commit).
2. Netlify redeploys automatically within a minute.
3. For a release, add a line to `CHANGELOG.md` and create a tag, e.g. `v1.1.0`
   (GitHub → Releases → Draft a new release).

Old versions stay in the commit history; Netlify can roll back to any deploy
from **Deploys → (pick a deploy) → Publish deploy**.
